1. Choose the spreadsheet

The month tabs must be named like AUG-26, with section titles in row 2, column headers in row 3 and data from row 4.

2. Check the mapping

Blank means "not mapped" - that column simply stays empty on the dashboard. Ranges look like AC:AI, single columns like AG.

Install into other spreadsheets

Creates a bound Apps Script inside each spreadsheet and copies this code into it. Each copy is standalone — it reads its own file and keeps its own settings, so this file can be unlinked afterwards. One-time prerequisite: turn on the Apps Script API at script.google.com/home/usersettings.
